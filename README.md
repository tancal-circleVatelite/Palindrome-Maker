# ばてライト回文メーカー

ばてライト回文メーカー は、日本語の文節データを使って回文候補を生成するアプリです。Tkinter ベースの GUI を使い、文節集合 CSV を読み込み、対象語句を指定して回文を生成し、結果を Excel 形式で出力できます。

## 使い方

1. リポジトリの `dist` フォルダにある `ばてライト回文メーカー.exe` をダウンロードします。
2. ダウンロードした EXE をそのまま実行します。
3. 「文節集合 CSV を選択」して、対象語句を入力します。
4. 出力先フォルダとファイル名を設定し、「回文を生成」を押します。
5. 生成中は候補が更新され、必要に応じて「生成中止」で停止できます。

> 追加のインストール作業は不要です。EXE をダウンロードして実行するだけで利用できます。

## ファイル概要

- `palindrome_gui.py`  
  Tkinter ベースの GUI 本体。CSV 選択、対象語句入力、生成実行、進捗表示、候補表示、出力設定を担当します。

- `palindrome_bunsetsu.py`  
  回文生成の中核ロジック。CSV 読み込み、文節探索、自然度計算、Excel 出力を実装します。

- `文節集合_JUMAN辞書.csv`  
  サンプルとして用意されている文節集合 CSV。GUI から読み込んで動作確認に使えます。

- `PalindromeMaker.spec`  
  PyInstaller 用のビルド設定ファイルです。Windows 向けの EXE 化時に使用します。

- `build_exe.bat`  
  Python 3.10 を使って EXE を再ビルドするためのバッチファイルです。

- `README.md`  
  この説明書です。使い方、ファイル構成、ライセンス情報などをまとめています。

- `dist/ばてライト回文メーカー.exe`  
  配布用の Windows 実行ファイルです。インストール不要でそのまま起動できます。

- `.gitignore`  
  Git 管理対象から除外するファイルやフォルダの設定です。

## 実行に必要なライブラリ

`palindrome_gui.py` を Python から直接実行する場合、以下のライブラリが必要です。

- Python 3.10 以上
- tkinter
- openpyxl

インストール例:

```bash
pip install tkinter openpyxl
```

> tkinter は標準ライブラリに含まれることが多いですが、環境によっては別途導入が必要な場合があります。

## 入力データ形式

CSV は次の形式を前提にしています。

```csv
text,reading,btype
あ,あ,名詞
...
```

- `text` : 文節の表記
- `reading` : その文節の読み
- `btype` : 任意の分類（省略可能）

## 出力内容

- 複数の対象語句がある場合は、各語句ごとに Excel ファイルが出力されます。
- 出力ファイル名の既定値は `Result` です。
- 複数語句指定時は、末尾に対象語句が追記されます。

## 補足

このリポジトリでは、GUI 側の操作は `palindrome_gui.py`、回文生成の処理本体は `palindrome_bunsetsu.py` に分離されています。アプリ本体の実行には、Python 3.10 系の環境、または配布済みの EXE を利用するのが簡単です。
