# Palindrome Maker

Palindrome Maker は、日本語の文節データを使って回文候補を生成するアプリです。Tkinter ベースの GUI を用いて、CSV から文節集合を読み込み、対象語句を選び、回文候補を Excel 形式で出力できます。

## 機能

- 文節集合 CSV を選択して読み込み
- 生成対象の語句を入力して管理
- 対象語句が CSV に存在しない場合は、実行時に一時的に追加して処理
- 回文候補を Excel 形式で出力
- 実行中の進捗と候補を GUI 上で表示
- 実行中に生成を中止できる

## 使い方

1. GitHub リポジトリの Releases または配布ページから `dist/PalindromeMaker.exe` をダウンロードします。
2. ダウンロードした EXE を実行します。
3. 文節集合 CSV を選択し、対象語句を入力します。
4. 出力フォルダとファイル名を設定し、「回文を生成」を押します。
5. 実行中は候補が随時更新され、必要に応じて「生成中止」で中断できます。

> 追加のインストール作業は不要です。EXE をダウンロードしてそのまま実行すれば利用できます。

## ファイル概要

- `palindrome_gui.py`  
  Tkinter による GUI 本体。CSV 選択、対象語句入力、生成実行、進捗表示、結果出力を担当します。

- `palindrome_bunsetsu.py`  
  回文生成の中核ロジック。文節データの読み込み、候補探索、自然度計算、Excel 出力処理を実装します。

- `文節集合_JUMAN辞書.csv`  
  サンプルとして用意されている文節集合 CSV。GUI 上で読み込んで試すための辞書データです。

- `HelloHello-H.otf`  
  フッター文字用のフォントファイル。配置されている環境では、そのフォントを使って表示します。

- `README.md`  
  この説明書。使い方、ファイル構成、ライセンス情報などを記載しています。

- `dist/PalindromeMaker.exe`  
  配布用の Windows 実行ファイル。インストール不要でそのまま実行できます。

- `.gitignore`  
  Git 管理対象から除外したい生成物や実行時ファイルの設定です。

## 必要なライブラリ一覧

`palindrome_gui.py` を Python から直接実行する場合、以下のライブラリが必要です。

- Python 3.10 以上
- tkinter
- openpyxl

インストール例:

```bash
pip install tkinter openpyxl
```

> tkinter は標準ライブラリに含まれることが多いですが、環境によっては別途導入が必要な場合があります。

## 入力データ形式

文節集合 CSV は、以下の形式を前提にしています。

```csv
text,reading,btype
あ,あ,名詞
...
```

## 出力内容

- 生成対象の語句が複数ある場合は、各語句ごとに Excel ファイルが出力されます。
- 出力ファイル名のデフォルトは `Result` です。
- 複数語句指定時は末尾に対象語句が追記されたファイル名になります。

## 補足

このリポジトリでは、GUI 側の制御と回文生成の中核処理が分離されており、UI は `palindrome_gui.py`、生成ロジックは `palindrome_bunsetsu.py` で管理されています。
