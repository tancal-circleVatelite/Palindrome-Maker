# Palindrome Maker

Palindrome Maker は、日本語の文節データを使って回文候補を生成する Python アプリです。Tkinter ベースの GUI で、CSV から文節集合を読み込み、対象語句を選び、複数の回文候補ファイルを出力できます。

## 機能

- 文節集合 CSV を選択して読み込み
- 生成対象の語句を入力して管理
- 対象語句が CSV に存在しない場合は、実行時に一時的に追加して処理
- 回文候補を Excel 形式で出力
- 実行中の進捗と候補を GUI 上で表示
- 実行中に生成を中止できる

## 必要条件

- Python 3.10 以上
- Tkinter
- openpyxl

## インストール

```bash
pip install openpyxl
```

## 実行方法

```bash
python palindrome_gui.py
```

## 入力データ

- 文節集合 CSV は、以下の形式を前提にしています。

```csv
text,reading,btype
あ,あ,名詞
...
```

- サンプルデータとして `juman_bunsetsu.csv` が含まれています。

## 出力

- 生成対象の語句が複数ある場合は、各語句ごとに Excel ファイルが出力されます。
- 出力ファイル名のデフォルトは `Result` です。
- 複数語句指定時は末尾に対象語句が追記されたファイル名になります。

## 使い方

1. 文節集合 CSV を選択します。
2. 生成対象語句を入力または貼り付けます。
3. 出力先フォルダとファイル名を設定します。
4. 「回文を生成」を押します。
5. 実行中は候補が随時更新され、必要に応じて「生成中止」で中断できます。

## 補足

このリポジトリには、文節データの CSV と GUI アプリケーションの本体が含まれています。回文生成の核となる処理は `palindrome_bunsetsu.py` にあり、Tkinter 側の UI は `palindrome_gui.py` で制御しています。
